27.1 Planning an Investigation

27.1.1 Key Steps

  1. Define the problem
    • Make a clear statement of the problem
    • Identify the independent variable (what you change)
    • Identify the dependent variable (what you measure)
    • Identify control variables (what you keep constant)
  2. Describe data collection
    • How the independent variable is varied
    • How variables are measured
    • How other variables are controlled
    • Arrangement of apparatus
  3. Describe data analysis
    • How data will be processed
    • Graphs to be plotted
    • Calculations to be performed
    • How conclusions will be drawn
  4. Safety precautions
    • Identify potential hazards
    • Suggest appropriate safety measures

27.2 Making Measurements

27.2.1 Avoiding Errors

Parallax Error - Position your eye perpendicular to the scale - Look straight at the measurement mark - Use a mirror behind the pointer if available

Zero Error - Check that instruments read zero when they should - For vernier calipers: close jaws completely and check reading - For ammeters/voltmeters: check with no current/voltage applied - Subtract zero error from measurements

Random Errors - Take multiple readings and calculate average - Repeat measurements to check consistency - Ignore anomalous results (after checking for mistakes)

27.3 Common Instruments

27.3.1 Length Measurements

Instrument Precision Range
Metre rule 1 mm Up to 1 m
Vernier calipers 0.1 mm 0–15 cm
Measuring tape 1 mm Several metres

Using a metre rule: - Align the object with the zero mark (or another mark if zero is damaged) - View at right angles to avoid parallax error - Record to the nearest mm

Using vernier calipers: - Check for zero error before use - Close jaws gently on the object - Read main scale to left of vernier zero - Find vernier division that aligns with main scale - Add vernier reading to main scale reading

27.3.2 Time Measurements

Instrument Precision
Stopwatch 0.01 s (display to 0.1 s)
Digital timer 0.01 s or better

Timing oscillations: - Ignore first few oscillations - Start timing when motion is steady - Time multiple oscillations (e.g., 20) - Calculate average: \(T = \frac{t}{n}\) - Human reaction time: ~0.3–0.5 s

27.3.3 Mass and Volume

Electronic balance: - Zero before use - Do not place wet objects directly on pan - Use container of known mass for powders/liquids

Measuring cylinder: - Place on level surface - Read at eye level with bottom of meniscus - Remove air bubbles before reading

Displacement method (irregular objects): - Record initial volume \(V_1\) - Immerse object completely - Record final volume \(V_2\) - Volume of object: \(V = V_2 - V_1\)

27.3.4 Temperature

Liquid-in-glass thermometer: - Do not use as a stirrer - Read to nearest half division - Avoid parallax error - Ensure bulb is fully immersed - Stir liquid for uniform temperature

27.3.5 Electrical Measurements

Ammeter: - Connect in series - Check zero error - Select appropriate range - Avoid parallax error - Break circuit after readings to minimize heating

Voltmeter: - Connect in parallel - Check zero error - Select appropriate range - Avoid parallax error

27.4 Recording Data

27.4.1 Tables

Requirements: - Column headings with quantity and unit (e.g., “Time/s”) - Consistent decimal places - Appropriate precision - Repeat readings where appropriate - No units in body of table

Example:

Length \(l\)/cm Time for 20 oscillations \(t\)/s Period \(T\)/s \(T^2\)/s²
20.0 18.2 0.91 0.83
40.0 25.6 1.28 1.64
60.0 31.4 1.57 2.46

27.5 Graphs

27.5.1 Drawing Graphs

Axes: - Label with quantity and unit (e.g., “Time/s”) - Use sensible scales (1, 2, 5, or multiples) - Avoid awkward scales (3, 6, 7, etc.) - Use more than half the graph paper in both directions - Origin not necessarily at (0,0)

Plotting points: - Mark clearly with × or ⊕ - Accuracy: ±½ small square - Use sharp pencil

Best-fit line: - Draw thin, smooth line - Equal number of points on each side - Ignore anomalous points (circle them) - Does not need to pass through all points - Use transparent ruler for straight lines

27.5.2 Analyzing Graphs

Gradient: - Draw large triangle (hypotenuse > ½ line length) - Show triangle on graph - \(\text{Gradient} = \frac{y_2 - y_1}{x_2 - x_1}\) - Calculate to 2–3 significant figures - Include units

Intercept: - Read where line crosses axis - Extrapolate if necessary - Include units

27.7 Safety in the Laboratory

27.7.1 General Rules

  1. Before starting:
    • Read all instructions carefully
    • Clear work area of unnecessary items
    • Identify potential hazards
  2. During experiment:
    • Wear eye protection when required
    • Follow instructions precisely
    • Do not perform unauthorized experiments
    • Keep work area tidy
    • Never leave heating apparatus unattended
  3. After experiment:
    • Turn off all equipment
    • Clean work area
    • Dispose of materials properly
    • Wash hands thoroughly

27.7.2 Specific Hazards

Electrical: - Check insulation is not damaged - Do not overload circuits - Use appropriate voltage - Turn off when not in use - Keep away from water

Heating: - Use heat-resistant mat - Handle hot apparatus with tongs - Allow time to cool - Point test tubes away from people

Radioactive sources: - Minimize exposure time - Maximize distance from source - Use shielding (lead containers) - Use tongs to handle sources - Store in locked cabinet

Glass: - Handle with care - Report breakages immediately - Do not use cracked glassware - Clean up broken glass safely

27.8 Evaluating Experiments

27.8.1 Identifying Errors

Systematic errors: - Consistent bias in measurements - Examples: zero error, calibration error, parallax error - Cannot be reduced by repeating

Random errors: - Unpredictable variations - Examples: reaction time, reading fluctuations - Reduced by taking averages

Anomalous results: - Clearly different from pattern - Check for mistakes - Repeat if possible - Exclude from analysis if justified

27.8.2 Improving Experiments

Suggestions for improvement: - Use more precise instruments - Increase number of readings - Extend range of values - Control variables more carefully - Reduce heat loss/energy loss - Minimize friction - Use data loggers for accuracy - Repeat readings for reliability

27.9 Data Analysis

27.9.1 Calculations

Significant figures: - Give answers to same sf as least precise data - Usually 2–3 sf for IGCSE - Do not round intermediate calculations

Uncertainty: - Assume ±10% at IGCSE level - Compare with expected values - Comment on accuracy

27.9.2 Conclusions

Writing conclusions: - State relationship found - Refer to graph/evidence - Compare with expected results - Comment on accuracy - Suggest improvements
